Principles

Five rules that shaped every screen

Simple first

Show the few numbers that matter now. Reserves, ownership and other detail belong in the full fund model, not onboarding.

One big number

Each screen has a hero figure in plum. Supporting numbers are smaller and sit below it.

Nudge, don’t block

Risky choices turn a soft amber with one calm sentence. Nothing is disabled, nothing flashes red.

Results come last

Inputs at the top, consequences below. The thing a choice produces sits at the bottom of the page.

Help is always there

Every step ends with the “Talk to the team” banner, just above the main button.

Layout

Stacked, full width, one idea per card

  • Page width 1040–1120px, 28px side padding
  • Order fund chip, eyebrow, title, lede, then cards, help banner and the main button
  • Cards 30–34px padding, 18px apart
  • Inside cards 16px between tiles, 24px between fields
  • Grids 2 or 3 equal columns inside a card, collapsing to 1 below 860px
  • No side columns next to the main content. They squeeze the work area.
  • Bottom space at least 52px of clear space at the bottom of every page

Words

How the product talks

Do

  • Talk to one person: “your fund,” “your list.”
  • Use sentence case everywhere, including buttons.
  • Say what a number means: “Roughly what you’d need committed before you can start investing.”
  • Be honest about estimates: “Potential, not promised.”
  • Name the next action: “Use this with your first 10.”

Don’t

  • Use jargon without a plain explanation next to it.
  • Write warnings in alarming terms: “Error,” “Invalid,” “Too risky.”
  • Use dashes in page titles.
  • Show a number without saying what it assumes.
  • Use generic labels like “Submit” or “Next.”

Tokens

Start every new page with these

Paste into the top of a new stylesheet. The color and font names match the prototype’s code, so components can be copied across as they are. The shape, shadow and gradient names are new shorthands for values the prototype writes out in full.
